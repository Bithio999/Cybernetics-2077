# Item IDs and commands

[Wiki home](index.md) · [Cyberware](cyberware.md) · [Quickhacks](quickhacks.md) · [Village services](ripperdocs.md)

Useful for server setup and Creative testing. Commands require cheats or operator permissions. The normal way to obtain cyberware is [ripperdoc stock](ripperdocs.md).

## Commands

```mcfunction
/cybernetics eddies add @s 50000
/give @s cybernetics2077:raven_microcyber_tier_3
/give @s cybernetics2077:overheat_tier_1
```
