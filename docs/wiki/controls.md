# Controls

[Wiki home](index.md) · [Cyberware](cyberware.md) · [Quickhacks](quickhacks.md) · [Village services](ripperdocs.md)

Default bindings can be changed under **Options → Controls → Cybernetics 2077**.

| Action | Control |
| --- | --- |
| Open cyberware viewer | Inventory → adjacent cyberware tab |
| Change viewed body system | A / D or category arrows |
| Return to overview / inventory | Esc |
| Navigate and select sockets | Tab / Enter |
| Open scanner | Hold V |
| Select a loaded quickhack | Mouse wheel while scanning |
| Queue the selected quickhack | Left-click while scanning a valid target |
| Deploy / retract Mantis Blades | G; both hands must be empty to deploy |
| Mantis light attacks | Left-click |
| Mantis lunge | Hold right-click ≥0.4 s, then release |
| Activate Berserk | I |
| Toggle Sandevistan | O |
| Use Blood Pump | H |
| Activate Optical Camo | C |
| Reinforced Tendons double jump | Jump again in midair |
| Fortified Ankles charged jump | Hold jump on ground, then release |
| Install/remove implants or chips | Shift-click in the appropriate menu |

With **TaCZ installed**, new default bindings use **Alt+V** for the scanner, **Alt+G** for blades, **Alt+H** for Blood Pump, **Alt+C** for camo, **Alt+O** for Sandevistan and **Alt+I** for Berserk. This avoids conflicting with the gun controls. Previously saved keybindings are kept; resolve existing conflicts in Options → Controls.

## Additional implants

**B:** open Titanium Bones’ carry reserve. **J:** activate Behavioral Imprint Faceplate after five seconds without attacking or taking damage. **O:** Sandevistan; **I:** Berserk. All bindings are configurable in Minecraft Controls.
