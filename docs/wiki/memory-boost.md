# Memory Boost

[Wiki home](index.md) · [Cyberware](cyberware.md) · [Quickhacks](quickhacks.md) · [Village services](ripperdocs.md)

<img src="assets/icons/memory_boost.png" alt="Memory Boost icon" width="48" height="48" class="item-icon">

| System | Tiers | Capacity |
| --- | --- | --- |
| Frontal Cortex | 2–5 | 18 |

Adds **1 maximum RAM**. Killing hostile mobs or combat opponents restores RAM; passive animals do not count. Requires an installed cyberdeck.

| Tier | RAM restored per enemy kill |
| --- | ---: |
| 2 | 0.75 |
| 3 | 0.95 |
| 4 | 1.15 |
| 5 | 1.35 |

Recovery cannot exceed the equipped deck's maximum RAM.
