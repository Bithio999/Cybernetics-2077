| Circulatory System | 1–5 | 14 |

Below **50% HP**, automatically uses an installed Blood Pump charge. If none is available, drinks a healing or regeneration potion from the main inventory/hotbar. Harmful mixed potions are skipped. Regeneration potions are not wasted while Regeneration is already active.

Consumes real charges/items and leaves the normal empty bottle. Checks every **0.5 seconds**, with at least **2 seconds** between automatic uses. Berserk blocks potion use, but permits Blood Pump. Also amplifies all healing received, including pump healing.

| Tier | Healing received |
| --- | ---: |
| 1 | +4% |
| 2 | +8% |
| 3 | +12% |
| 4 | +16% |
| 5 | +20% |
