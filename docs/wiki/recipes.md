# Crafting and obtaining cyberware

[Wiki home](index.md) · [Cyberware](cyberware.md) · [Quickhacks](quickhacks.md) · [Village services](ripperdocs.md)

Buy implants, cyberdecks and quickhack chips from [ripperdocs](ripperdocs.md). These items have **no crafting or smithing upgrade recipes**. To move to a higher tier, buy that tier from an eligible doctor's daily stock and install it. Normal Street Cred requirements apply.

[Damaged cybernetic parts](enhanced-mobs.md#using-a-part) give a matching-tier implant discount.

## Cybernetics Bench

| | | |
| --- | --- | --- |
| Iron ingot | Glass | Iron ingot |
| Redstone | Crafting table | Redstone |
| Iron ingot | Empty | Iron ingot |

Right-click to install/remove implants. Breaking the bench leaves installed cyberware with your character.

The bench recipe unlocks after obtaining redstone. It installs/removes cyberware; it does not craft implants or raise their tier.
